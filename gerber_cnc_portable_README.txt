Gerber CNC - Portable

Contiene el ejecutable "gerber_cnc.exe" compilado con PyInstaller (onefile).

Cómo usar:
1. Extrae el contenido del ZIP en una carpeta.
2. Ejecuta `gerber_cnc.exe` (doble clic) o usa `run_gerber_cnc.bat`.

Requisitos en Windows:
- Windows 10/11.
- Si el ejecutable falla al iniciarse, instala Visual C++ Redistributable 2015-2022 (x64) desde Microsoft.

Notas:
- El ejecutable incluye la mayoría de dependencias. Si necesita archivos adicionales (p. ej. ejemplos), colóquelos junto al ejecutable.
- Para depuración, abre un símbolo del sistema y ejecuta `gerber_cnc.exe` desde la carpeta para ver mensajes de salida si los hubiera.
